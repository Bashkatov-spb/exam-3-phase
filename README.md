# Задания для 3 фазы

## Задание 1: Попугай
1. Создать компонент с контролируемым полем для ввода текста.
2. Вывести текст контролируемого поля на страницу — например, в теге `<p>`.
3. Сделать компонент с кнопкой, при клике на которую к тексту добавляется восклицательный знак — по одному знаку на каждое нажатие кнопки.

## Задание 2: Калькулятор
1. Создать компонент калькулятора с полем для отображения результата.
2. Добавить кнопки для цифр (0-9) и основных операций (+, -, *, /).
3. Реализовать логику вычислений с возможностью выполнения последовательных операций.
4. Добавить кнопку очистки (C) для сброса калькулятора.
5. Добавить кнопку равно (=) для получения результата.
6. Обработать ошибки (деление на ноль, некорректные операции).

## Задание 3: Список дел (Todo App)
1. Создать компонент для управления списком задач.
2. Добавить возможность добавления новых задач через поле ввода.
3. Реализовать переключение статуса выполнения задач (выполнено/не выполнено).
4. Добавить фильтрацию задач (все, активные, выполненные).
5. Реализовать удаление отдельных задач.
6. Добавить функцию очистки всех выполненных задач.

## Задание 4: Виджет погоды
1. Создать компонент для отображения информации о погоде.
2. Добавить поле поиска по городам.
3. Отображать температуру, описание погоды, влажность и скорость ветра.
4. Использовать иконки для визуального представления погодных условий.
5. Добавить список популярных городов для быстрого переключения.
6. Реализовать анимации загрузки и обработку ошибок.

## Задание 5: Таймер и Секундомер
1. Создать компонент с двумя режимами: секундомер и таймер обратного отсчета.
2. Для секундомера: запуск, пауза, сброс с отображением времени.
3. Для таймера: установка времени, обратный отсчет, уведомление о завершении.
4. Добавить визуальный индикатор прогресса для таймера.
5. Реализовать форматирование времени (часы:минуты:секунды).
6. Добавить анимации и звуковые уведомления.
