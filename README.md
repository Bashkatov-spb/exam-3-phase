# 🧮 Счетчик - React TypeScript приложение

Современное приложение-счетчик с улучшенным UX и доступностью.

## ✨ Функциональность

- ➕ **Увеличение/уменьшение** значения счетчика
- 🔢 **Настраиваемый шаг** (от 1 до 100)
- 🔄 **Сброс счетчика** в ноль
- ↶ **Отмена операций** - возможность отменить последнее действие
- 📋 **История операций** - просмотр всех выполненных действий с временными метками
- 🗑️ **Очистка истории** - удаление всех записей истории
- ✅ **Валидация ввода** с уведомлениями об ошибках
- ♿ **Полная доступность** (ARIA-атрибуты, семантическая разметка)
- 📱 **Адаптивный дизайн** для всех устройств
- 🎨 **Современный UI** с анимациями и градиентами

## 🚀 Технологии

- **React 18** с TypeScript
- **Hooks** (useState, useCallback)
- **Строгая типизация** с интерфейсами
- **CSS3** с современными эффектами
- **Accessibility** (ARIA, семантика)

## 🛠️ Установка и запуск

```bash
# Установка зависимостей
npm install

# Запуск в режиме разработки
npm start

# Сборка для продакшена
npm run build
```

## 📋 Требования

- Node.js 16+
- npm или yarn

## 🎯 Особенности реализации

- **Компонентная архитектура** - каждый элемент UI в отдельном компоненте
- **Типизация** - полная типизация всех пропсов и состояний
- **Производительность** - использование useCallback для оптимизации
- **Валидация** - проверка корректности ввода в реальном времени
- **История операций** - полное отслеживание всех действий пользователя
- **Отмена операций** - возможность вернуться к предыдущему состоянию
- **UX** - плавные анимации и визуальная обратная связь
- **Доступность** - поддержка скрин-ридеров и навигации с клавиатуры
